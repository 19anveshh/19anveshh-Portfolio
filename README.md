## Overview

This is my personal portfolio website — a showcase of my journey as an AI Engineering student, featuring projects in Retrieval-Augmented Generation (RAG), Large Language Models (LLMs), AI agents, and full-stack development.

Built with a modern, responsive design featuring glassmorphism UI, animated backgrounds, and smooth interactions.

## 🚀 Live Demo

**[View Portfolio](https://github.com/19anveshh/19anveshh-Portfolio)**

## ✨ Features

- **🎨 Modern UI** — Glassmorphism design with animated Earth background
- **⚡ Fast & Lightweight** — Pure HTML/CSS/JS, no heavy frameworks
- **📱 Responsive** — Works on desktop and mobile devices
- **🎯 Project Showcase** — Highlights AI/ML projects with live links
- **📬 Contact Section** — Easy ways to get in touch

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/19anveshh/19anveshh-Portfolio.git
cd 19anveshh-Portfolio

# Open in browser
open index.html
# or just double-click index.html
```

No build step required — it's a static HTML page.
